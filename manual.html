Technician manual

Fit a unit in a car, pair it with the gate's beacon, and test it.

Set it up

  1. Fit the unit. Stick the case in the glove box with Velcro. Any position works, but it must not slide or tumble.
  2. Power it. Plug in a USB supply that turns off with the ignition, and start the car. One long beep means no beacon is paired yet.
  3. Start the hotspot. Triple-click the button on top of the case. You hear three short beeps. It does not start by itself.
  4. Join it. In your phone's Wi-Fi settings, choose YogiGate-XXXX. The password is password. If the phone warns about no internet, stay connected.
  5. Open the page. Go to http://192.168.4.1, and type the http:// too.
  1. Pair the beacon. On the Beacon tab, either type its MAC, or tap Scan and then Use. At the bench, you can also hold the button for 3 s and hold the beacon against the unit. You hear short, short, long.
  2. Test it, parked. On the Status tab, Signal shows a number and Live motion moves when you shake the unit. Close the glove box and tap Press the remote. You hear one short beep, and the gate must open from the parking spot.
  3. Test it, driving. Start the car and wait: the gate must stay shut. Drive off: the gate opens within a few seconds, with no beep.

The button

One clickPress the remote
Two clicksSet the set point here
Three clicksStart the hotspot
Hold 3 sPair a beacon held close

Good to know

Replace the remote's battery every year, because the unit cannot tell when it dies. Advanced mode, at the bottom of the Settings tab, shows every setting, Reset to defaults, Factory reset and firmware upload. Change password is on the same tab. This manual is also on the page's Help tab.

What each sound means

No beep when the gate opens by itself. That is correct.

One short: remote pressed by hand
Two short: pairing, so hold the beacon close
Three short: the hotspot is starting
Short, short, long: saved
Two rattles: that did not work, so try again
One long at power-on: no beacon is paired yet
Three long: the motion sensor failed

What each colour means

The LED is on the C6 board inside the case, so you only see it with the case open.

WhitePressing the remote
Fast bluePairing
Green, 2 sSaved
Cyan, 2 sHotspot starting
3 red blinksThat did not work
2 red, every 10 sMotion sensor failed
Slow amberNo beacon, first 30 s
OffNormal

If it goes wrong

No hotspotTriple-click, and listen for three short beeps.
Page will not openJoin by hand in Wi-Fi settings, and type http://.
Gate stays shutCheck the remote's battery and range, then the Signal on the Status tab.
Opens from the streetRaise the set point on the Settings tab.
Opens while parkedFix the unit so it cannot move, then rate that trip on the Logs tab.
Three long beepsCheck the sensor's four wires. Until fixed, the gate can open from the spot.
Remote's LED stays onIts two wires are swapped.
